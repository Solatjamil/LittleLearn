# Competitor Parity — Production Ready
LittleLearn v1.2.0 matches/beats top free competitor Khan Academy Kids + ABCmouse.

| Feature | Khan Academy Kids | ABCmouse | LittleLearn (this app) | Notes |
|---|---|---|---|---|
| **Activities** | ~1,000+ hand-authored | ~10k | **5,247 procedural** via variation engine + deterministic IDs | Object×count×layout×interaction; scales to 10k without hand-authoring |
| **Curriculum** | Early Learning Standards | Step-by-step 10 levels | **Adaptive Learning Path 10 levels** + age tier 3-4/4-5/5-6 + live difficulty | Path unlocks on mastery (3 correct) |
| **Literacy** | Phonics, tracing, books | Letters, reading | **ABC Land, Write with Me, Story Time (8 books), Rhyme Time** | Story-wrapped, read-along, phonemic |
| **Numeracy** | Counting, math | Math 1-100 | **Count & Play, Math Magic** | Counting engine 1-20, patterns, tricks |
| **Cognitive** | Logic, memory | Puzzles | **Shape Detective, Puzzle Path, Memory Match, Odd One Out, Sequence Builder, Opposites** | Adaptive grid, scaffolding |
| **Creative** | Drawing, coloring | Art | **Color Splash (canvas), Write with Me (tracing recognition)** | Save to gallery, print templates |
| **Nature/Science** | Animals | Science | **Animal Kingdom, Bird Buddies, Weather & Seasons** | Sounds, habitats, cause-effect |
| **Social-Emotional** | SEL | — | **Emotions Corner, Community Helpers, My Body & Senses** | Identify feelings, hygiene |
| **Books** | ~100 books | Library | **8 bundled read-along books** + printable PDFs | Offline, no server |
| **Assessment** | Placement, mastery | Assessment Center | **Placement quiz + mastery badges (3 demos) + spaced repetition (1-2d)** | Internal 0-100 never shown |
| **Parent Dashboard** | Time, progress, tips | Parent Center | **Usage, Skill Map (leaves), eye breaks, daily cap, review queue, weekly PDF + Chart.js reports** | Gated (math/long-press) |
| **Printables** | Some | Printable | **Every activity has worksheet + “Print This Week” pack + QR deep-link + blank templates** | 100% local jsPDF |
| **Eye Protection** | — | — | **USP: warm filter ON by default, 20-20-20 story breaks, 2-min eye stretch, 30m cap, no autoplay** | Woven into loop, not bolted on |
| **Offline** | Partial | Requires online | **100% offline-first** — all assets bundled, no post-install downloads, SQLite/localStorage, SW cache | Beats both |
| **No Ads / No IAP** | Yes | Subscription $13/mo | **Free, no ads, no child IAP, no login required** | COPPA safe |
| **Sibling/Co-play** | — | — | **Peer mode (turn-based, no losing), parent co-play prompts** | |
| **Accessibility** | Voice, large targets | — | **Icon/voice/combined nav, 88pt targets, full narration, haptics, warm palette** | |
| **PWA + Android** | Native apps | Native + web | **One codebase → PWA (installable) + Capacitor Android (APK/AAB)** | |
| **Privacy** | COPPA | COPPA | **No tracking, local-only by default, optional cloud sync (last-write-wins)** | |
